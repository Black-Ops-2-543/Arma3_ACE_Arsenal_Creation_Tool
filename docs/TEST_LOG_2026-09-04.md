## Problems discovered and resolved

1. Packaged generated SQF initially produced a preprocessor `Missing ]` error. Safe doubled-quote strings fixed it.
2. Stable Eden IDs between 2 and 63 characters were incorrectly rejected because length validation used set membership rather than a range. The check now uses inclusive bounds.
3. Malformed object/access fields could produce engine parameter errors before diagnostics. Type-safe extraction now lets shared preflight report the real fault.
4. Zeus Assign did not always use the operator-entered slot display name when resolving an embedded configuration. The server handler now does.
5. Test-harness assumptions about tag ordering, highlight row indexes, Unicode clipboard mode, module creation, and exact parser wording were corrected so assertions test product behavior rather than fixture accidents.
