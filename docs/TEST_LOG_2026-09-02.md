## Eden assignment defect found and resolved during the pass

### RACA-TEST-007 — Dashboard could not commit the custom array attribute directly

- Severity before mitigation: High.
- Reproduction: Select a dashboard row, choose an Arsenal Configuration, and use **Apply to Object**.
- Initial result: Arma rejected both `set3DENAttribute` and `set3DENAttributes` for the custom array-valued attribute even though the same control saved correctly through Eden's native Attributes window.
- Resolution: The dashboard still attempts the documented scripted setters first. When the engine rejects them, RACA opens the selected object's native Attributes lifecycle with a one-shot pending assignment, activates Eden's own save control, rereads the stored value, and reports success only after an exact match.
- Final verification: Assignment, dashboard refresh persistence, confirmed removal, and a second assignment all passed in the final build.

This fallback is deliberately guarded: failure to retain the exact value is reported as a failure, not as a successful update.
