## Confirmed defects

### RACA-TEST-001 — Catalogue row body click does not toggle inclusion

- Severity: Medium
- Area: Creator catalogue
- Reproduction:
  1. Open Restricted Arsenal Creator.
  2. Load a populated draft.
  3. Left-click the body of an item row rather than its checkbox.
- Expected: The clicked row toggles immediately, as required by `IN_GAME_TEST_CHECKLIST.md`.
- Actual: The row is only selected. Status text says, “Row selected. Press Space or click its checkbox to include or exclude.”
- Workaround: Click the checkbox or press Space.

### RACA-TEST-002 — Duplicate-import confirmation has an unlabeled action

- Severity: Medium
- Area: JSON and SQF import
- Reproduction:
  1. Export a preset as JSON or reusable SQF.
  2. Import the same preset while its name already exists.
  3. Observe the Duplicate preset confirmation.
- Expected: All three actions are clearly labeled and fully legible.
- Actual: `Overwrite` and `Import Copy` are visible, but the middle action has no visible label. Some button text is vertically clipped at the tested 1280×991 window size.
- Workaround: Use the visible `Import Copy` or `Overwrite` actions; avoid the unlabeled middle action.

### RACA-TEST-003 — Compatibility results overlap across columns

- Severity: Medium
- Area: Creator Compatibility Check
- Reproduction:
  1. Open a populated preset.
  2. Open Compatibility Details.
  3. View a long diagnostic such as `CATALOG_SCOPE` at approximately 1280×991.
- Expected: Message, source, mod, and add-on columns remain separate and readable.
- Actual: Long messages and source/mod/add-on values overlap adjacent columns. Severity filtering still works.

### RACA-TEST-004 — Eden configuration footer controls overlap and clip

- Severity: High
- Area: Eden Restricted Arsenal Configuration dialog
- Reproduction:
  1. Place an object in Eden.
  2. Open Object Attributes > Restricted Arsenals.
  3. Open Configure Slots at approximately 1280×991.
- Expected: Apply, dashboard, assignment, access test, cancel, help, status, and mission-preflight controls are individually visible and usable.
- Actual: `Apply Configuration` overlaps dashboard/help/status controls. The `ASSIGN TO SELECTED`, `TEST ACCESS`, and `CANCEL` region is clipped or covered, and the mission-preflight status text is truncated.
- Impact: Core slot configuration can still be saved and applied, but several footer tools are difficult or impossible to use reliably at this size.

## Tooling and harness issues

### RACA-TEST-005 — Automated-test preparation requires a newer .NET API

- Severity: Medium
- Area: `tools/prepare-autotest.ps1`
- Reproduction: Run the script with the installed Windows PowerShell/.NET environment.
- Expected: The isolated autotest profile and launch arguments are prepared.
- Actual: `[System.IO.Path]::GetRelativePath` is unavailable, so preparation stops after staging files.
- Workaround used: Launch the already staged isolated profile manually.
- Recommended direction: Compute the relative path with an API supported by Windows PowerShell 5.1, or require and verify PowerShell 7 before doing any staging work.

### RACA-TEST-006 — Multiplayer smoke mission reports a stale dependency warning

- Severity: Low
- Area: `tests/multiplayer/RACA_Rehearsal.VR/mission.sqm`
- Actual server warning: `You cannot play/edit this mission; it is dependent on downloadable content that has been deleted. a3_characters_f`
- Note: The mission still started, configured the RACA object, accepted the initial client, and produced valid rehearsal evidence. The mission declares `A3_Characters_F`; its dependency metadata should be regenerated or normalized in the current Eden version.
